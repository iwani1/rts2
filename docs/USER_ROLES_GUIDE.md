# User roles guide — draft

The system is not yet operational and account creation/authentication is not implemented. Roles in the current proposal are Super Administrator, Operations Manager, Dispatcher, Fleet Manager, Corporate HR Administrator, Driver, Employee/Passenger, Rental Customer, Finance Officer, and Maintenance Technician. Intended scopes and proposed permissions are in `PERMISSIONS.md`; that matrix requires owner approval. Never share credentials or assign roles based on this draft. A role guide for live workflows will be written as features are approved and implemented.
